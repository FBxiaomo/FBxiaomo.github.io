# Study-Note 写作后台部署

网站继续部署在 GitHub Pages，文章继续保存在 Study-Note；Cloudflare Worker 仅负责 GitHub 登录和请求网站更新。

## 当前固定地址

- 网站：`https://fbxiaomo.github.io`
- 写作入口：`https://fbxiaomo.github.io/admin/`
- Worker：`https://study-note-oauth.1092277506.workers.dev`
- GitHub OAuth 回调：`https://study-note-oauth.1092277506.workers.dev/callback`

## 1. 创建 Worker

Cloudflare → Workers & Pages → Create application → Start with Hello World。名称为 `study-note-oauth`，部署默认示例，保留生成的 workers.dev 地址。

## 2. 创建 GitHub OAuth App

打开 <https://github.com/settings/applications/new>：

| 字段 | 填写内容 |
| --- | --- |
| Application name | Study-Note 写作后台 |
| Homepage URL | `https://fbxiaomo.github.io` |
| Authorization callback URL | `https://study-note-oauth.1092277506.workers.dev/callback` |

保存后生成一个 Client Secret。只在自己的 Cloudflare 密钥设置中粘贴，不放进代码、不提交到仓库、不发送到聊天。

## 3. 替换 Worker 代码并保存密钥

1. 打开本项目 `workers/study-note-oauth/worker.mjs`，复制全部内容。
2. Cloudflare 打开 `study-note-oauth` → Edit code，替换默认代码，Deploy。
3. Settings → Variables and Secrets → Add，两项都选择 Secret：
   - `GITHUB_CLIENT_ID`：OAuth App 页面上的 Client ID。
   - `GITHUB_CLIENT_SECRET`：新生成的 Client Secret。
4. 保存并部署设置。
5. 访问 Worker 的 `/health`。配置完整后会返回 `ready: true`，不会显示密钥。

网站来源默认固定为 `https://fbxiaomo.github.io`，允许的 GitHub 登录名默认固定为 `FBxiaomo`。可以额外设置 `ALLOWED_GITHUB_ID` 为账号的数字编号进行双重校验；未设置时仍会通过 GitHub API 验证登录名。更换账号或域名时须同步修改这两处配置。

如使用命令行部署，可在 Worker 目录使用 Wrangler；`wrangler.jsonc` 中只有公开设置，密钥仍通过 Secret 保存。

## 4. 准备旧文章

运行 `node scripts/prepare-cms-content.mjs`，会在 `.cache/blog-sync/cms-prepared/` 生成缺少编辑器信息头的旧笔记副本。核对后把这些副本更新到 Study-Note 的相同路径；不改正文，保留日期和现有网址。

这是一次性适配。之后直接在写作后台新增、修改文章。

## 5. 发布网站并验证

`cms.config.json` 已填写 Worker 地址。需要把网站当前改动推送上线，正式写作入口才会生效。

本地执行：

```text
pnpm test:cms
pnpm test:blog
pnpm build
```

正式登录必须从线上网站的 `/admin/` 进入。本地预览可查看界面，但 OAuth 回传固定到线上来源，不接受 localhost。

上线后验证：站主登录成功，其他 GitHub 账号被拒绝；保存一篇草稿并确认 Study-Note 有对应提交；取消草稿后发布，检查网站工作流和文章展示；最后确认原有三篇文章网址未变。

## 发布与故障处理

编辑器保存成功后会尝试请求 Worker `/publish`，用当前登录账号的授权触发网站工作流；失败时保留已保存文章，页面显示提示，可点“更新网站”重试，也可在 GitHub Actions 中手动运行部署。删除文章后请点击“更新网站”。原来的每 6 小时同步任务仍保留。

OAuth 密钥更换或授权撤销后，更新 Cloudflare Secret 并重新登录即可。不要在共享设备保持登录。
