这里是第一篇文章。

为什么又搞一个博客？因为我需要一个**完全属于自己**的地方——不被平台限流，不被算法决定谁看得到，改版也不会被通知。内容放在 GitHub 仓库里，一个 Markdown 文件就是一篇文章，写完 push，一分钟后就上线。

## 这个站怎么搭的

技术栈很简单：

- **Astro** —— 构建时把 Markdown 编译成纯 HTML，默认零 JavaScript
- **GitHub Actions** —— 每次 push 到 main 自动构建并部署到 GitHub Pages
- **Content Collections** —— 文章的 frontmatter 带类型校验，写错字段构建就报错

```bash
# 本地预览
pnpm dev

# 构建 + 部署（push 就自动做）
git push
```

## 打算写什么

> 写作的本质是把想不清楚的东西，逼到能写下来的程度。

大概三类东西：

1. **技术笔记** —— 踩过的坑，以及为什么踩
2. **项目记录** —— 从想法到落地的过程，包括失败的部分
3. **乱七八糟** —— 读到的东西、想到的事

如果这些内容对你有用，那就更好了。
